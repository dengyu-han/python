# 基于 RAG 与工具调度的 ReAct 智能体 Agent

基于 Function-Calling 手写的多工具智能体，大模型自主决策工具调度，覆盖**本地知识库问答（RAG）**、**联网检索**、**网页精读**与**文生图 / 图生图**，并内置**短期 + 长期双记忆**。检索无命中自动转联网兜底，抓取前置 SSRF 防护。

## 技术栈

Python · FastAPI · ChromaDB · OpenAI Function-Calling · httpx / BeautifulSoup · LangChain（框架对照）

## 目录结构

```
├── agent.py            主程序（ReAct 决策循环 + Function-Calling 工具调度 + 双记忆）
├── tool_server.py      FastAPI 工具服务（联网搜索 / 网页抓取，含 SSRF 防护）
├── chroma.py           向量库增量入库与脏分片管理
├── examples/           LangChain 封装对照版（学习用，非主程序，运行需自配 .env）
└── legacy/             早期独立脚本（项目无关，仅存档）
```

## 工具一览

| 工具名 | 功能 |
| --- | --- |
| `get_current_time` / `calculate_add` | 内置原子工具：查询时间、数字相加 |
| `rag` | 语义检索本地知识库，距离阈值过滤低相关片段，增强组装后供 LLM 作答 |
| `web_search` | 联网搜索（FastAPI 服务，本地知识库无命中时兜底触发） |
| `web_fetch` | 网页正文精读（前置 SSRF 防护） |
| `image_generate` | 文生图 / 提示词 + 参考图生图 |

## 核心特性

- **RAG 全链路**：PDF/TXT 解析与重叠分片（200 字符窗口 / 30 重叠）→ 向量化入库 → 语义检索 Top-K → 距离阈值过滤 → 增强组装（片段 + 用户问题 + 防幻觉约束）→ 无命中自动转联网兜底。资料不足主动告知"知识库无相关内容"，拒绝编造。
- **向量库增量与脏清理**：以文件 MD5 为文件级指纹增量入库，内容未变直接跳过、仅重写变更文件切片，避免全量重建；自动清理源文件已删除的残留切片，防止数据冗余。
- **双记忆机制**：短期记忆超窗由 LLM 摘要压缩控制长会话上下文；长期记忆按轮次向量化入库，作答前语义召回相关历史实现跨会话记忆，并按天数滚动清理防库膨胀。
- **工程解耦与安全**：联网搜索 / 网页抓取拆分独立 FastAPI 服务，与决策逻辑解耦；抓取前置 SSRF 防护，域名预解析获取全部真实 IP 并按网段校验，覆盖回环、内网、链路本地（含云元数据）等危险地址。
- **手写 Agent 与 LangChain 对照**：手写原生实现并与 LangChain 封装方案对照，理解工具调用底层逻辑，量化封装方案的便利与黑盒成本。

## 运行效果（真实日志摘录）

两条典型调度链路（节选自 `agent_run.log`）：

**① 知识库命中 —— 本地 RAG 直接作答**
```
用户: gdb的基本命令有哪些
→ 大模型决策调用工具: rag（query='gdb 基本命令 常用命令 调试'）
→ 进入检索功能，检索到相关内容，返回给大模型，内容长度:200
→ 大模型无需调用工具，直接返回模型回答
```

**② 检索不足 —— 自动转联网兜底**
```
用户: colcon 的基本操作有哪些
→ 大模型决策调用工具: rag（query='colcon 基本操作 常用命令'）
→ 检索不到相关内容，返回空，转用互联网搜索
→ 触发 web_search / web_fetch，精读网页后返回模型回答
```

> 说明：上表为初始构建存档日志，运行你自己的会话时链路一致，最终回答以当次 LLM 输出为准。

## 运行方式

1. 配置 `.env`：

   ```
   API_KEY=<你的模型 API Key>
   TAVILY_API_KEY=<你的 Tavily API Key>
   ```

2. 启动工具服务：

   ```bash
   python tool_server.py
   ```

3. 另开终端启动主程序：

   ```bash
   python agent.py
   ```
